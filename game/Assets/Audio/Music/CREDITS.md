# Музыка

Все треки — **HydroGene**, набор «High Quality 8-bit / Chiptune Musics»:
https://hydrogene.itch.io/high-quality-8-bit-musics

Лицензия **CC0** (по словам автора на странице набора): можно использовать в любых, в том числе
коммерческих, проектах, указание автора не обязательно. Указываем из уважения.

| `music_game_2` | 03. Boss Battle | забеги, по очереди |
| `music_game_3` | 04. Mechanical Complex | забеги, по очереди |

Перекодировано из MP3 320 кбит/с: `.ogg` (Vorbis, q3 — петля без шва) и `.mp3` (96 кбит/с — запасной
для Safari). Все треки зациклены.
