# ChronoLift (Хронолифт)

Аркадная игра про лифт и остановку времени для **Яндекс.Игр** (WebGL, HTML5).
Игрок поднимается на лифте всё выше, а на каждом этаже его ждут ловушки.
Единственная защита — **заморозка времени**: зажми экран (или пробел), чтобы
остановить механизмы и проскользнуть между ними.

## Игровая механика

- **Заморозка времени** — основной ресурс. Полоса энергии тратится, пока время
  остановлено, и восстанавливается, пока идёт. Управление намеренно минимальное:
  один ввод — один навык (модель «one-button game» из лекций по геймдизайну).
- **5 типов ловушек**, каждая со своим телеграфом и паттерном:
  лазер (луч + перезарядка), диск-пила (движение по траектории),
  шипы (подъём из пола), пресс (падающая гильотина), тесла (разряд по цепи).
- **Мини-игры на этажах** — разнообразят ритм: «Калибровка» (тапай в момент
  попадания стрелки в сектор) и «Зарядка» (успей набрать энергию за время).
- **Процедурная генерация этажей** с гарантией проходимости: телеграфы ловушек
  всегда длиннее порога реакции, энергии на этаж всегда хватает с запасом
  (проверено аудитором `test/audit_passability.js`).
- **Обучение в раннем доступе**: welcome-сцена → 5 обучающих этажей
  (по одной ловушке каждая, с подсказками и стрелкой-подсветкой) → игра.
- **Настройки** — звук, повтор обучения, сброс прогресса с подтверждением
  (покупки при сбросе сохраняются).

## Ретеншн (удержание игроков)

- **Ежедневная награда + streak** — 7-дневный цикл (25 → 300 монет), серия
  входов; popup при входе, до геймплея.
- **Ежедневные миссии** — 3/день из пула 11 (детерминированный выбор по дате, у трёх миссий дня разные счётчики),
  прогресс копится в живом геймплее (этажи, идеальные остановки, комбо,
  freeze-секунды, миниигры, возрождения, монеты), сброс в 00:00 по местному времени, награда —
  монеты; сцены «Missions» + бейдж в меню.
- **Достижения** — 7 карточек (коллекция + мастерство), награда — монеты.
- **Сохранения** — локальные + облако Яндекс.Игр (streak и миссии переживают
  смену устройства), миграция версий сейва.
- Обоснование каждого механизма (психология, anti-dark-pattern, метрики) —
  `docs/RETENTION.md`.

## Монетизация (Яндекс.Игры)

- **Rewarded-реклама**: продолжить забег после смерти, получить монеты.
- **Interstitial**: между забегами.
- **Лидерборд** «chronolift_floors» — рейтинг по пройденным этажам.
- **Скины за достижения**: mint / violet / gold открываются достижениями
  (серия этажей, идеальные прохождения, монеты).
- **Платежи**: покупка «Отключить рекламу» (проверка через `getPurchases`).
- **Облачные сохранения** через Player API.

## Технологии

- **Phaser 3** (WebGL-рендер, канвас-сцены, tweens для анимаций) — движок игры. Мир — 480×800,
  холст — в разрешении экрана (`RENDER_SCALE` в `Core/Config.js`), поэтому картинка чёткая на любом экране.
- **Blender** — 3D-модели лифта и ловушек (`blender/assets.blend`), экспорт в
  GLB; спрайты для релиза отрендерены в PNG 256 px.
- **Яндекс Games SDK 2.0**: LoadingAPI.ready, GameplayAPI start/stop,
  пауза/возобновление платформы, i18n-язык, реклама, лидерборды, платежи.
- Без сборщика: игра — статический сайт, `index.html` в корне `game/`.

## Запуск локально

Нужен любой статический сервер (из-за CORS на загрузку ассетов):

```bash
cd game
python -m http.server 8000
# открыть http://127.0.0.1:8000
```

Для локального теста без кабинета Яндекса есть страница `game/test-yandex.html` —
она подключает полный мок SDK (`game/test/mock-yandex.js`): авторизация,
облако, лидерборд, покупки, реклама, пауза платформы.

## Тестирование

Автотесты управляют Chrome через CDP (порт задан внутри скриптов):

Для браузерных тестов сначала запустить сервер на порту 8321:
`cd game && python -m http.server 8321`. Каждый тест печатает `ALL PASS`
или `FAIL` и возвращает код выхода 1 при ошибке. Переменная `CHRONO_DPR` задаёт плотность экрана
тестового браузера: `CHRONO_DPR=3 node test/cdp_test.js` проверяет игру с отрисовкой в масштабе 2,75.

```bash
node test/check_pages.js       # без браузера: обе страницы подключают одни и те же скрипты
node test/check_daily.js       # без браузера: смена дня в 00:00 по местному, выбор миссий
node test/cdp_test.js          # сцены + автотест обучения, ERRORS должно быть []
node test/probe_playthrough.js # игровой бот проходит этажи
node test/audit_passability.js # аудит проходимости генератора (без браузера)
node test/probe_yandex.js      # мок Яндекс SDK: облако, lb, платежи, реклама
node test/probe_pause.js       # пауза/возобновление платформы
node test/probe_missions.js    # миссии: хуки в геймплее, забор награды, смена дня
node test/probe_revive.js      # после смерти: кнопки «реклама», «за монеты», «отказаться»
node test/shots_defense.js     # переснять скриншоты для docs/DEFENSE.md
```
