# ХРОНОЛИФТ — GDD (Game Design Document)

Hyper-casual аркада для Яндекс Игр (WebGL, Phaser 3). Забег 30–90 секунд, один ввод (зажим/тап), мгновенный рестарт.

---

## 1. Elevator Pitch

> Ты — пилот испытательного лифта с хроно-приводом. Шахта кишит ловушками.
> **Зажми экран — время остановится**, ловушки замрут, лифт проскользнёт мимо.
> Отпустишь — время пойдёт. Энергия не бесконечна: пустая батарея = перегрузка и верная смерть.
> Поднимись как можно выше, собери монеты, открой скины с бонусами и бей рекорды друзей.

---

## 2. Рынок и обоснование

Hyper-casual рынок 2025–26 (по обзорам Kevuru Games, Capermint, Innovecs, Pixel Genesys):

- **Тап/тайминг — одна из топ-механик** жанра (рядом с runner и stack). Низкий порог входа, высокий skill ceiling.
- Одна механика + короткий сессионный цикл (30–60 с) + мгновенный рестарт = стандарт удержания.
- Основной доход — **реклама с вознаграждением** (eCPM выше interstitial в 3–5 раз), второй поток — IAP у «китов» (1–2 %).
- Визуальные зоны поражения и честные хитбоксы обязательны: hyper-casual аудитория «не читает» игру — она реагирует на цвет (красное = смерть).
- Разнообразие одной механики — через набор препятствий и микро-вариации (у нас: 5 типов ловушек + 2 миниигры на том же вводе).

Дифференциация: механика «остановки времени» (freeze) вместо привычного прыжка/уклонения; понятные хитбоксы; скины с реальными бонусами (не только визуал).

---

## 3. Целевая аудитория

- 12–35 лет, мобильный веб (Яндекс Игры — преимущественно Android/RU).
- Сессия: поездка/перерыв, 2–5 забегов подряд.
- Мотивация: рекорд (лидерборд), коллекция скинов, ежедневная серия входов.

---

## 4. Core Loop (игровой цикл, 30–90 с)

```
СТАРТ ──► подъём ──► ловушка впереди ──► ЗАЖАЛ (заморозка, тратит энергию)
   ▲                                        │
   │                                   ловушка замерла
   │                                        │
   │◄── проскочил ── ОТПУСТИЛ (энергия копится) ◄──
   │
   └── смерть ──► возродиться (rewarded / 100 монет) ──► или ИТОГИ ──► ЕЩЁ РАЗ (1 тап)
```

Ключевые решения игрока каждые 2–4 секунды:
- **Когда зажать** (тратится энергия ~26/с) и **когда отпустить** (реген ~17/с).
- Проскочить «идеально» (заморозка именно в красной зоне) = комбо-множитель монет.

Прогрессия сложности внутри забега: скорость растёт (95 → 270 px/s), циклы ловушек ускоряются, с 6-го этажа — пары ловушек (combo-двери).

## 5. Механики

### 5.1 Заморозка времени (ядро игры)
- Зажим = время останавливается: ловушки замирают (безопасны), лифт продолжает движение.
- Энергия: 100 ед.; заморозка −26/с; реген +17/с (модификаторы скинов).
- Перегрузка (0 энергии): форс-резюм + блокировка заморозки до 30 энергии.
- Идеальная остановка (freeze в красной зоне) → комбо ×2…×6 к монетам.

### 5.2 Ловушки (5 типов, low-poly модели Blender → спрайты)
| Ловушка | Поведение | Читаемая зона |
|---|---|---|
| Лазерная сеть | цикл вкл/выкл | горизонтальная полоса |
| Пила | летает по этажу синусом/пинг-понг | круг вокруг диска |
| Шипы | выстреливают вниз с задержкой | прямоугольник под плитой |
| Гидропресс | поднят → предупреждение → удар → удержание | прямоугольник удара |
| Тесла-дуга | заряд → разряд по ширине шахты | горизонтальная линия |

Опасность показывает сама ловушка, совпадая с зоной поражения: красное — опасна сейчас; жёлтое, трижды мигающее — включится через секунду (прицельный луч лазера, искры теслы, проявляющиеся шипы, тень под прессом). Рамки зон — режим в настройках. Коллайдер игрока — по силуэту спрайта.

### 5.2.1 Ритм: серии и передышки (`Gameplay/FloorPlanner.js`)
- Ловушки идут **сериями по 2–4 угрозы** (этаж с двумя ловушками — две угрозы), после серии — **передышка**:
  увеличенный промежуток шахты, за который энергия гарантированно восстанавливается до полной.
- **Гарантия проходимости.** Стратегия «держать заморозку всё время, пока игрок в опасной зоне» проходит
  любую ловушку при любой фазе, идеальная игра тратит не больше. Генератор ставит ловушку, только если эта
  стратегия с ошибкой 20% (держит на 20% дольше, в том числе там, где мог бы восстанавливаться) не опустит
  энергию ниже 2. Цена этажа = (высота опасной зоны + рост игрока 94 px) / скорость лифта × энергию.
- На старте лифт медленный (95 px/с), зону приходится держать до 2 с, поэтому серии короче, передышки
  длиннее; к 40-му этажу (270 px/с) в серию помещаются четыре тяжёлые ловушки подряд.
- До 28.10 серий не было: ловушки шли подряд, и даже безошибочный игрок погибал в ~20% забегов до 60-го
  этажа (`docs/FIXES.md`, пункт 16).

### 5.2.2 Звук
- **Жёлтая зона** — три сигнала в такт вспышкам, каждый выше предыдущего; тембр свой у каждой ловушки
  (лазер — писк, тесла — жужжание, шипы — стук, пресс — низкий удар). Громкость — по расстоянию: впереди
  нарастает по мере приближения, позади быстро затихает. Звуки самих ловушек — по тому же правилу.
- **Музыка** (HydroGene, CC0): меню — «I am not clumsy», забеги — «Perilous Dungeon», «Boss Battle»,
  «Mechanical Complex» по очереди. Всё зациклено, на время рекламы музыка на паузе.

### 5.3 Миниигры (на том же вводе, каждые 4 этажа после 4-го)
- **«Калибровка хроноядра»** — маркер крутится по кольцу, короткий тап в зелёном секторе.
- **«Заряд хроно-ячейки»** — игла летает ping-pong, короткий тап в центральной зоне.
- Награда за успех: +12–15 энергии, +5 монет. Промах — без штрафа (только упущенный бонус).
- Разнообразят ритм, дают «передышку» и экономический кран, не ломая core loop.

## 6. Meta Loop (межсессионный цикл)

```
забег ──► монеты ──► скины (бонусы) / возрождение (sink)
   │            │
   │            └──► достижения ──► награды + скин «Хроно-агент»
   │
   └──► рекорд этажей ──► онлайн-лидерборд (Яндекс)
                 │
   ежедневная награда + серия входов (streak, 7 дней)
                 │
   ежедневные миссии (3/день, прогресс в живом геймплее, см. 6.4)
                 │
   IAP: отключение рекламы / мешок монет / эксклюзивный скин
```

### 6.1 Экономика
**Краны (faucets):**
| Источник | Кол-во | Примечание |
|---|---|---|
| Прохождение этажа | 10 очков | лидерборд-метрика |
| Идеальная остановка | 2–8 монет | комбо-множитель |
| Монеты в шахте | 1–4 на этаж | 75% этажей |
| Достижение | 20–150 монет | 7 достижений |
| Ежедневная награда | 25–300 | шкала 7 дней (streak) |
| Миссии дня | 3 × 30–80 | 3/день из пула 11 (6.4) |
| Миниигра | +5 | каждые 4 этажа |
| ×2 итогов (rewarded) | ×2 монеты забега | |
| IAP «Мешок монет» | 500 | |

**Ванны (sinks):** возрождение за 100 монет (главный sink, лимит 1/забег); планируемые: смена ежедневного контракта, крафт-скины.
**Антиинфляция:** монеты только soft-валюта, цены фиксированные, единый sink с реальным спросом (возрождение). Премиум-валюта отсутствует — не дробим экономику.

### 6.2 Скины (4 шт., дают пассивные бонусы)
| Скин | Бонус | Открытие |
|---|---|---|
| Бортинженер (orange) | баланс | стартовый |
| Хроно-агент (mint) | +25% реген энергии | достижение «10 этажей за забег» |
| Ночной страж (violet) | +15% макс. энергии | достижение «25 идеальных суммарно» |
| Хроно-султан (gold) | +10% макс. энергии | IAP 149 ₽ |

### 6.3 Достижения (7)
Первый подъём (3 этажа) · Смотритель (10) · Хроно-ветеран (25) · Монетный магнат (15 монет/забег) · Идеальный тайминг (25 идеальных) · Завсегдатай (10 игр) · Серия ×3 (3 дня входа).

### 6.4 Ежедневные миссии (retention-контракт дня)
Три миссии в день из пула 11 (`MISSIONS`, `Config.js`), детерминированный выбор
по дате (FNV-1a hash от `YYYY-MM-DD`) — одинаковый на всех устройствах игрока.
Сброс в 00:00 UTC (`MissionService.rolloverIfNeeded`), награда — монеты
(забирается в сцене «Missions», бейдж на кнопке в меню).

Метрики привязаны к геймплею: этажи/забеги/идеальные остановки/монеты/
freeze-секунды/миниигры/возрождения (sum за день) и этаж-за-забег/комбо (max за день).

Пул: 30/60 этажей · 3/5 забегов · 5 идеальных · 25 монет · 30 с заморозки ·
2 миниигры · 1 возрождение · 20 этажей за забег · комбо ×4 (награды 30–80).

Психологическое обоснование (Зейгарник, goal gradient, commitment & consistency,
variable reward, anti-dark-pattern) — `docs/RETENTION.md`.

## 7. Обучение (FTUE)

1. **Welcome-экран**: история в 4 строки + CTA (вход через Яндекс или «играть без входа»).
2. **Ежедневная награда** сразу после входа — первый позитивный момент.
3. **5 уроков** — первые 5 этажей с фиксированными ловушками и замедленными циклами (×0.62), подсказка показывается строго одна (урок ближайшего этажа), без наложений:
   1 этаж — лазер + «ЗАЖМИ ЭКРАН»; 2 — пила; 3 — шипы + энергия; 4 — пресс; 5 — тесла.
4. **Рука-подсказка** «ЗАЖМИ!» пульсирует внизу экрана, пока игрок не выполнил первую заморозку.
5. **Интро угроз**: при первой встрече каждого типа ловушки (в т.ч. после обучения) — тост «НОВАЯ УГРОЗА».
6. Обучение считается пройденным после 5 этажей (`tutorialDone`), повторно не показывается.

## 8. Монетизация

| Формат | Где | Правило |
|---|---|---|
| **Rewarded** | возрождение (1/забег) | кнопка «бесплатно (реклама)» или 100 монет — игрок выбирает |
| **Rewarded** | ×2 монеты на экране итогов | всегда по желанию |
| **Interstitial** | каждый 2-й game over | кулдаун 90 с, не чаще; выключается IAP «Тишина» |
| **IAP** | «Тишина» 99 ₽ — отключить межсессионную рекламу | восстанавливается через покупки Яндекса |
| **IAP** | «Мешок монет» 49 ₽ — 500 монет | sink-ускоритель |
| **IAP** | Скин «Хроно-султан» 149 ₽ | эксклюзив + бонус энергии |

Принципы: rewarded всегда инициируется игроком; interstitial только на естественной паузе (game over), с кулдауном; IAP не продаёт силу напрямую, только комфорт/коллекцию.

## 9. Яндекс-сервисы (реализовано)

- **Авторизация** + облачные сохранения (восстановление прогресса на любом устройстве).
- **Лидерборд** `chronolift_floors` (топ-5 + позиция игрока).
- **Платежи**: каталог 3 товаров, покупка, восстановление (`getPurchases`), консьюм.
- **Реклама**: rewarded + fullscreen через `Yandex.jslib`-мост (mock вне платформы).
- **Fallback**: вне Яндекс Игр все сервисы деградируют в локальные (localStorage) — игра полностью играбельна.

## 10. Аналитика

События (AnalyticsService, кольцевой буфер → Яндекс Метрика на проде):
`run_start` (скин) · `run_death` (причина, этаж) · `run_end` (этажи/очки/монеты) · `run_milestone` (каждые 10 этажей) · `revive` (метод) · `minigame_start/result` (тип, успех) · `menu_play` · `menu_missions` · `missions_reset` / `mission_claim` · `daily_claim` (streak) · `auth_success` · покупки/достижения.

Ключевые метрики: D1/D7 retention, длина забега (медиана этажей), конверсия revive-оффера, ARPDAU по рекламе.

## 11. План запуска на Яндекс Играх (чек-лист)

1. Иконка 512×512 + обложки (2–3 скриншота геймплея с хитбокс-подсветкой).
2. Консоль разработчика: включить лидерборд `chronolift_floors`, заполнить каталог товаров (3 SKU), привязать рекламные блоки.
3. Проверить `index.html` единственным входом, `Yandex.jslib` в Plugins/WebGL.
4. Модерация: возраст 0+, без сторонних ссылок; тест покупок в дебаг-режиме.
5. Софт-запуск: мониторинг метрик 1 неделя → баланс скорости/энергии по `run_death`-причинам.
