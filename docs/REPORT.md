# ХРОНОЛИФТ — доклад к защите «Удержание игроков» (10 баллов)

Команда 9. Для защищающего: что показать и чем обосновать каждый пункт рубрики.
Подробная памятка со скриншотами — `docs/DEFENSE.md`, обоснование механик — `docs/RETENTION.md`.

## Где игра

- **Без интернета (на паре):** скачать https://github.com/nelex12/chronolift (Code → Download ZIP),
  распаковать, открыть двойным щелчком **`chronolift-offline.html`** в Chrome, Edge или Яндекс Браузере.
- **Онлайн:** https://nelex12.github.io/chronolift/game/test-yandex.html (работает и с телефона).
- Обе версии — с имитацией Яндекс Игр: вход, облако, лидерборд, покупки и реклама работают как на платформе.

**Игра в одну фразу:** лифт едет вверх через этажи с ловушками; зажми экран или пробел — время
остановится, ловушки замрут, и лифт проскользнёт мимо. Энергия на остановку тратится и восстанавливается.
Красная зона убивает сейчас, жёлтая мигающая станет красной через секунду.

## Рубрика «удержание»: требование → функции → обоснование

Пути — от `game/Assets/Scripts/`.

### 1. Daily Reward — 2 балла (минимум курса: 1 система)
- **Что показать:** при входе всплывает «Ежедневная награда» с серией дней.
- **Код:** `DailyService.pending()` решает, положена ли награда и какая серия: вчера заходил — серия +1,
  пропустил день — серия с 1. `DailyService.claim()` начисляет монеты и запоминает день. Награды за 7 дней —
  `DAILY_REWARDS` в `Core/Config.js`: 25, 50, 75, 100, 150, 200, 300. Окно — `MenuScene.maybeShowDaily()`,
  показывается до игры. День меняется в полночь по местному времени (`DailyService._dateStr`).
- **Почему удерживает:** награда растёт с серией, пропуск обнуляет её — появляется причина зайти завтра
  (неприятие потери).

### 2. Daily Missions — 2 балла (минимум курса: 3 миссии)
- **Что показать:** меню → «Миссии»: три карточки с полосой прогресса, у выполненных — «Забрать».
- **Код:** `MissionService.selectFor(дата)` выбирает 3 миссии из 11 (`MISSIONS` в `Core/Config.js`),
  одинаковые на всех устройствах игрока и всегда на разные действия. `rolloverIfNeeded()` — новые миссии
  в полночь. `progress(type, amount, mode)` копит прогресс, `claim(id)` выдаёт награду. Экран —
  `UI/MissionsScene.js`, там же таймер «новые через N ч M мин».
- **Почему удерживает:** незавершённая задача держится в памяти (эффект Зейгарник), каждый день новый
  набор целей.

### 3. Achievements — 2 балла (минимум курса: 5 достижений)
- **Что показать:** меню → «Достижения»: 7 карточек с прогрессом и наградой.
- **Код:** 7 достижений — `ACHIEVEMENTS` в `Core/Config.js` (Первый подъём, Смотритель, Хроно-ветеран,
  Монетный магнат, Идеальный тайминг, Завсегдатай, Серия ×3). `AchievementService.progressOf()`
  считает прогресс, `check()` открывает выполненные в конце забега (`GameScene.gameOver()`). Экран —
  `UI/AchievementsScene.js`. Достижения открывают скины (`UI/SkinsScene.js`).
- **Почему удерживает:** коллекция с видимым прогрессом — долгая цель на недели, в отличие от дневных миссий.

### 4. Интеграция с геймплеем — 1 балл
- **Что показать:** в забеге всплывает «🎯 МИССИЯ ВЫПОЛНЕНА»; на экране итогов — блоки «Достижения»
  и «Миссии».
- **Код:** прогресс миссий считает сам геймплей через `GameScene.trackMission()`: этажи, идеальные
  остановки, комбо и монеты — в `onFloorPassed()`, монеты — в `collectCoins()`, секунды остановки
  времени — в `update()`, возрождения — в `revive()`, забеги — в `gameOver()`, мини-игры —
  `Minigames.finish()`. Итоги забега — `UI/GameOverScene.js`.
- **Почему засчитывается:** миссии выполняются обычной игрой, а не отдельным «гриндом».

### 5. Сохранение состояния — 1 балл
- **Что показать:** нажать F5 — монеты, серия, миссии и достижения на месте.
- **Код:** `Core/State.js`: `saveNow()` пишет в браузер и в облако Яндекса (`YandexClient.cloudSave`),
  `resolveSaveFromCloud()` при старте берёт более свежую версию (по времени сохранения), `migrateSave()`
  переносит старые сохранения в новую версию.
- **Почему засчитывается:** серия и миссии не теряются при смене устройства.

### 6. UI / UX — 1 балл
- **Что показать:** красный значок с числом на кнопке «Миссии», полосы прогресса, кнопка «Забрать»
  только у выполненных, всплывающие сообщения.
- **Код:** значок — `MissionService.claimableCount()` в `UI/MenuScene.js`; полосы — `MissionsScene`,
  `AchievementsScene`; сообщения — `UI/Hud.js` (`toast`, длинный текст переносится).
- **Почему засчитывается:** игрок видит, где его ждёт награда, без навязчивых окон.

### 7. Обоснование retention-дизайна — 1 балл
- **Где:** `docs/RETENTION.md` разложен по этим же пунктам: механика → психологический механизм →
  реализация → ожидаемый эффект; метрики для проверки (возвраты на 1-й и 7-й день, доля забравших
  награду); что сознательно не сделано (таймеры давления, ограничение забегов, платное возрождение).

## Сценарий на 2–3 минуты

1. Фраза про игру (выше), открыть игру: ежедневная награда → пункт 1.
2. «Забрать» → значок на «Миссиях» → экран миссий → пункты 2 и 6.
3. «Играть», пара этажей, «Миссия выполнена» → пункт 4.
4. Проиграть → экран итогов с достижениями и миссиями → пункты 3 и 4.
5. F5 → всё сохранилось → пункт 5.
6. «Почему это удерживает» одной фразой и ссылка на `docs/RETENTION.md` → пункт 7.

## Если спросят

- **Почему не Unity?** Phaser 3 — движок для браузерных игр, сборка — веб-страница, сразу подходит
  для Яндекс Игр. Структура папок повторяет шаблон курса.
- **Игру точно можно пройти?** Да: ловушки идут сериями по 2–4, после серии — передышка до полной
  энергии; ловушка ставится, только если её можно пройти даже с ошибкой 20%. Проверено расчётом на
  2000 шахт и симуляцией 300 забегов (`test/audit_passability.js`, `test/sim_players.js`).
- **Что если пропустить день?** Серия начинается с первого дня, награду задним числом не отнимаем.
- **Как выбираются миссии?** По дате: на всех устройствах игрока в один день одни и те же три миссии.
